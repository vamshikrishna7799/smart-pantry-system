# Smart Pantry System

A Smart Pantry Management System that helps users track pantry items, monitor stock levels, manage expiry dates, and receive notifications for low-stock or expired products. The system aims to reduce food waste and improve household inventory management through automation and intelligent tracking.

---

## Features

### 🔐 User Authentication
- User Registration
- User Login & Logout
- Secure Password Management

### Pantry Management
- Add New Items
- Update Item Details
- Delete Items
- View Pantry Inventory

### 📅 Expiry Tracking
- Monitor Expiry Dates
- Highlight Expired Items
- Notify Upcoming Expirations

### 📉 Stock Monitoring
- Track Item Quantities
- Low Stock Alerts
- Automatic Inventory Updates

### 🔍 Search & Filter
- Search Items by Name
- Filter by Category
- Filter by Expiry Status

### 📊 Dashboard
- Total Items Overview
- Low Stock Summary
- Expired Items Summary
- Pantry Statistics

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/smart-pantry-system.git
```

### Navigate to Project Directory

```bash
cd smart-pantry-system
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the root directory.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Start the Application

```bash
npm start
```

For development mode:

```bash
npm run dev
```

## 🚀 Usage

1. Register a new account.
2. Login to the system.
3. Add pantry items with quantity and expiry date.
4. Monitor inventory from the dashboard.
5. Receive alerts for:
   - Low stock items
   - Expired products
   - Upcoming expirations
6. Update or remove items as needed.
